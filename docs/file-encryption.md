# Шифрування файлів

## Алгоритм

Файли зберігаються лише в зашифрованому вигляді. Використовується
AES-256-GCM з бібліотеки `cryptography`: один ключ 256 біт, випадковий
96-бітний IV для кожної операції та 128-бітний тег автентичності.

Контейнер:

```text
[12 байт IV] [16 байт Tag] [шифротекст]
```

`AESGCM.encrypt` повертає `ciphertext || tag`, тому модуль розділяє
результат і зберігає тег перед шифротекстом. Під час читання тег
приєднується назад і передається в `AESGCM.decrypt`.

## AAD

Додаткові автентифіковані дані прив'язують контейнер до запису:

```text
docvault|v1|<document_id>|<owner_id>
```

Якщо файл перекласти в інший документ або змінити власника в БД,
перевірка тега не пройде.

## Ключ

`VAULT_FILE_KEY` — 64 hex-символи (32 байти). Значення за
замовчуванням призначене лише для локального запуску. У робочому
середовищі ключ зберігають у менеджері секретів, а для ротації
використовують старий ключ лише для читання вже створених файлів.

## Маршрути

| Метод | Шлях | Що робить |
|---|---|---|
| GET | `/api/v1/documents` | список своїх документів |
| POST | `/api/v1/documents/upload` | шифрує та зберігає файл |
| GET | `/api/v1/documents/{id}/download` | розшифровує та віддає файл |
| DELETE | `/api/v1/documents/{id}` | видаляє контейнер і метадані |
| GET/POST | `/api/v1/documents/{id}/comments` | коментарі до документа |

Документ зберігається під UUID-іменем `<uuid>.enc`; оригінальна назва
лежить у БД і використовується лише для `Content-Disposition`.
Розмір файлу обмежений 10 МБ.

## Перевірка цілісності

```powershell
python tools/integrity_check.py
```

Скрипт показує IV, Tag і hex контейнера, розшифровує його, потім
інвертує один байт і намагається розшифрувати ще раз. Очікування:

```text
--> УСПІХ: InvalidTag — AES-GCM заблокував підроблений файл.
```

Те саме перевіряє `tests/test_documents_integrity.py`: після зміни байта
маршрут скачування повертає `409 integrity_failed`.

## Інтерфейс

Після входу доступні дві вкладки: **Профіль** і **Документи**.
У «Документах» є завантаження, список своїх файлів зі скачуванням і
видаленням та коментарі до вибраного документа.
